# Artificial Neural Network with tanh Activation

## Description
This project implements a simple Artificial Neural Network (ANN) using:

- Random weights in range [-0.5, 0.5]
- tanh activation function
- Bias values:
  - b1 = 0.5 (hidden layer)
  - b2 = 0.7 (output layer)

The network performs a forward pass and prints the final output.

## Network Structure
- 2 Input Neurons
- 2 Hidden Neurons
- 2 Output Neurons
- Activation Function: tanh
- Random weight initialization

## Technologies Used
- Python
- NumPy

## How to Run

```bash
python ann_tanh.py
```
